# 本机调用保护

保护层用于降低异常请求的持续影响。它不能看到上游平台的识别过程，不能保证账号不会被限制，也不提供身份隐藏或绕过检测功能。

## 默认规则

| 条件 | 本服务行为 |
| --- | --- |
| 同时已有 2 个对话请求 | 返回 429，不排队、不发上游请求 |
| 一分钟内已有 20 次模型调度 | 返回 429 和 Retry-After，本机换号尝试也计数 |
| 上游 401 / 403 / 明确账号限制 | 暂停后续模型调用，不继续切换账号 |
| 上游 429 | 暂停，等待人工检查配额和上游限制 |
| 渠道校验 11128 | 暂停，不继续尝试其他账号 |
| 一分钟累计 3 次其他上游故障 | 暂停，避免形成重试风暴 |
| 保护状态文件损坏 | 按暂停处理 |
| 凭据库不可用 | 插件桥停止初始化，不把未知凭据当作不存在 |

可用 `GATEWAY_MAX_ACTIVE_CHATS` 与 `GATEWAY_MAX_DISPATCH_PER_MINUTE` 调低默认上限。
上游驱动正常完成的内部令牌续期不算作一次新的模型调度。

暂停只取消本服务仍在处理的转发，已经送达上游的请求未必会在上游同时停止。
插件内部重试、其他客户端直接访问插件网关或上游的请求，不在本服务控制范围。
本服务当前使用一个 worker；多个进程不能共享并发计数和取消信号。

## 页面提醒与诊断

渠道页与配额页显示调用保护条。发生异常时提示复制诊断信息交给 AI 或维护者检查，暂停时修改页面标题。
页面打开且有本机会话时每 5 秒读取一次本机保护状态；回到页面时立即刷新。浏览器已关闭时不会发送系统通知。
不会自动调用 AI、上传日志或发送消息。

复制内容只含固定原因分类、HTTP 状态、发生时间、调用上限和状态保存结果，不包含账号名称、ID、消息、Cookie、访问令牌、刷新令牌或上游错误原文。
排查时先提供这份诊断和版本号，需要补充日志时应先去除密钥。

## 恢复

暂停状态写入本机 `.gateway-protection.json`，重启后仍暂停。不要把此文件放入 Git 或发布包。
若磁盘写入失败，当前进程仍暂停，页面会提示保存失败；这种情况下无法保证跨重启保留。

检查网络、配额、授权和上游错误后，点击「检查后恢复」并确认。
恢复不修改账号禁用、冷却、模型开关或凭据，不会解除上游限制，也不会自动重发失败请求。

## 本地验证

在 gateway 目录安装开发依赖后运行：

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe -m pytest tests/test_protection.py -q
node tests/quota-data.test.mjs
```

保护测试使用临时文件与假上游；不创建厂商登录、不调用真实模型。
