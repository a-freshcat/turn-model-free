t 连接本机网关

输入网关密钥后即可读取本机号池。密钥只在本机做会话校验，不会离开这台机器。

密钥在哪里？
  1. 启动窗口：双击 launch-desktop.cmd / launch-web.cmd 后， 黑窗口会打印一行 Gateway key: …，直接复制那串。
  2. 密钥文件：已保存的密钥就在 gateway\.gateway-api-key
  3. 环境变量：如果你自己指定过 GATEWAY_API_KEY，那就是你设的那个值。
  4. 想换一个：删掉上面那个密钥文件并重启网关，会重新生成一个新密钥。

桌面启动
三种启动方式，互斥地占用同一个端口
TurnModelFree.exe双击即开 · 无黑窗口
发布包根目录里的 TurnModelFree.exe 用 pythonw 静默拉起 桌面窗口，没有控制台。关窗口时服务一起退出。要在桌面放快捷方式： powershell -File scripts\install-shortcut.ps1（加 -StartMenu 也进开始菜单）。
launch-desktop.cmd排障入口 · 带黑窗口
同样的桌面窗口，但保留控制台：会打印网关地址与 Key， 出错时错误也在这里。exe 起不来时双击它看原因。它不该被删掉。
launch-web.cmd只开浏览器 · 不开窗口
起网关并打开系统浏览器指向本页。适合只用浏览器、不想要独立窗口的场合。
三者抢同一个端口（默认 8199）。已经开着一个时再开第二个， 新进程会先尝试接管上一次没关干净的自身实例；占端口的是别的程序时， 报错会点名端口与占用进程。
换端口：TurnModelFree.exe --port 8300 / launch-desktop.cmd --port 8300。
