# gateway-web-search

独立网页搜索技能，Python 3.10+，仅用标准库。解压到客户端技能目录，配置环境变量或私有 config.json，然后选择此技能即可使用。需要 turn-model-free 1.2.13+ 或实现相同 /v1/search 扩展的自建/授权共享网关，不附送账号或配额。

安装与使用：https://github.com/a-freshcat/turn-model-free/blob/v1.2.13/docs/web-search.md

config.example.json 仅为示例；配置 Key 后的 config.json 应留在本机，避免分享。
