# 单独安装技能与共享网关

## 只下载技能即可使用

Release 附件 `gateway-imagegen-v1.2.13.zip` 是独立的生图技能。无需下载全部网关源码或自己维护账号池；它需要一个支持 Images API 的服务地址、服务提供方发放的访问 Key，以及 Python 3.10+。脚本仅用标准库，无 pip 依赖。

解压后的 `gateway-imagegen/` 中包含 SKILL.md 和 scripts/。放进客户端支持的技能目录，或通过客户端导入该文件夹，再刷新技能列表。DSH 可放入其 `~/.dsh/skills/`，Codex 可放入 `~/.codex/skills/`；其他客户端使用各自支持的技能安装方式。已有内置 imagegen 技能不会被覆盖，选择 `gateway-imagegen` 即可。只支持工具/HTTP 调用而不支持 SKILL.md 的客户端，也能直接按 [Images API 文档](image-generation.md) 接入。

在启动客户端的环境或客户端支持的凭据设置中配置：

```text
GATEWAY_BASE_URL=https://提供方给出的网关地址/v1
GATEWAY_API_KEY=提供方给出的调用凭据
GATEWAY_IMAGE_MODEL=提供方给出的图像模型名
```

本机自建服务可用 `http://127.0.0.1:8199/v1`。环境变量修改后需让客户端进程重新读取。最后一项可省略，使用此项目时由网关选择已配置的图像型号。

技能是调用器，模型推理和配额由网关提供；单独安装技能不会附送账号、免费配额或公共服务地址。v1.2.13 另提供 gateway-web-search 独立搜索技能包，安装与切换方法见 [搜索说明](web-search.md)。搜索和生图是不同附件，可分别安装。

## 使用别人授权共享的池子

提供方运行网关并保管自己的账号及 Google 登录态。使用方仅配置服务地址、调用凭据和模型，不交换 Cookie、refresh token 或账号密码。请求内容会经过提供方的服务，适合双方明确授权、信任且了解数据处理方式的协作。

共享使用同一上游账号的真实配额。客户端数量不会增加配额，仍应尊重提供方的并发、速率、内容规则与上游授权限制。本仓库不提供公共号池，也不保证第三方服务的稳定性和保密性。

## 提供共享服务前

当前核心网关的 Key 同时能调用管理 API，不能把它直接当普通成员调用 Key 分发。保留后端在回环/私网，由反代提供 HTTPS；在反代侧为每位使用者设置独立调用鉴权、速率和并发限制，并在验证通过后用服务端持有的网关 Key 转发。后端端口不要暴露给使用者。

对外只放行实际需要的 `/v1/chat/completions`、`/v1/models`、`/v1/images/generations`、可选 `/v1/search` 和图片签名下载路径，拒绝 `/admin/*`、`/ui/*`、管理网页及 OAuth 回调等管理路由。独立调用凭据的发放、撤销和用量核算由部署方的反代或现有 API 管理平台实现；本版本没有内置多租户 Key 管理或计费。

跨多节点时，URL 图片需要会话保持或共享存储；使用本技能的 b64_json 模式可避免图片下载落到其他节点。图片链接一小时有效，应视为临时的图片查看凭据。
